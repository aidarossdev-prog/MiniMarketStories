\# 🛒 Mini Market Stories



\*\*Mini Market Stories\*\* es un videojuego de exploración tridimensional desarrollado en Unity como parte de un proyecto académico de desarrollo de videojuegos para dispositivos móviles.



El jugador puede recorrer libremente un pequeño minimercado, utilizando controles de movimiento y salto mientras una cámara realiza un seguimiento estable del personaje.



\## 🎮 Características principales



\- Entorno tridimensional con estética low-poly y colores pastel.

\- Escenario de minimercado con estanterías, mostrador y caja registradora.

\- Movimiento del personaje en los ejes X y Z.

\- Salto del personaje en el eje Y.

\- Cámara con seguimiento suavizado y desplazamiento relativo constante.

\- Sistema de colisiones mediante Rigidbody y Colliders.

\- Menú principal con navegación entre escenas.

\- Pantalla de instrucciones.

\- Interfaz adaptada a orientación horizontal.

\- Joystick virtual y botón táctil de salto.



\## 🕹️ Controles

|---|---|---|

| Avanzar | W / ↑ | Joystick |

| Izquierda | A / ← | Joystick |

| Derecha | D / → | Joystick |

| Saltar | Espacio | Botón SALTAR |



\## 🗺️ Escenas del videojuego



\*\*MainMenu:\*\* pantalla principal con opciones para iniciar el videojuego, consultar las instrucciones y salir.



\*\*MiniMarket:\*\* escenario tridimensional donde el jugador puede explorar el minimercado.



\*\*HowToPlay:\*\* pantalla que explica los controles y el funcionamiento básico del videojuego.

\## 🚀 Cómo ejecutar el proyecto



1\. Descargar o clonar este repositorio.

2\. Abrir Unity Hub.

3\. Seleccionar \*\*Add project from disk\*\*.

4\. Elegir la carpeta del proyecto.

5\. Abrirlo con Unity 6000.5.9f1.

6\. Abrir la escena `MainMenu` desde `Assets/Scenes`.

7\. Presionar \*\*Play\*\* para iniciar.



\## 📚 Primera entrega



Esta primera etapa contempla:



1\. Implementación de una interfaz gráfica funcional para navegar entre escenas.

2\. Movimiento del personaje en los tres ejes del espacio tridimensional.

3\. Sistema de seguimiento estable de cámara en los ejes X y Z.

4\. Conservación de una distancia relativa entre la cámara y el personaje.
